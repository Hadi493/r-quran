# R-Quran

Simple Quran reader for Linux.

## Demo

<video src="r-quran-demo.mp4" controls width="100%"></video>

## Run

AppImage:
```
./R-Quran-x86_64.AppImage
```

From source:
```
PYTHONPATH=src python3 -m r_quran.app
```

## Features
- Two-page book view
- Juz, Surah, bookmarks
- Light / dark / sepia
- Offline, no page numbers
- Fullscreen with F
