# R-Quran

Simple Quran reader for Linux.

https://github.com/Hadi493/r-quran/blob/master/r-quran-demo.mp4

[Download demo](r-quran-demo.mp4)

## Run

AppImage:
```
./R-Quran-x86_64.AppImage
```

From source:
```
PYTHONPATH=src python3 -m r_quran.app
```

## Build AppImage
```bash
./build-appimage.sh
```

## Features
- Two-page book view
- Juz, Surah, bookmarks
- Light / dark / sepia
- Offline, no page numbers
- Fullscreen with F
